Riffle

Card game analytics: metagame share, deck-building odds, and price history, with the math shown.

Riffle collects its own data every day: card data, prices from the stores and price sites, and tournament decklists. A player's collection and decks go in too, so it can say what a deck is missing and what finishing it costs.

The methods and the code are public, on GitHub under the AGPL. Riffle is in development.

By Brandon M. Keltz.
